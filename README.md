# metaphysics-web · 玄学占卜

多算法玄学占卜平台：内置**大六壬、小六壬、六爻、梅花易数**，AI 会自主起课、精确断卦，并把每步推导和术语讲清楚。中式「青花 · 玄」界面（亮/暗主题）。

## 怎么开始

```bash
npm install
npm run dev     # 打开 http://localhost:3000
```

## 怎么用

### 🔮 智能占卜（推荐）

在对话框输入你的事，例如：

- `看看我最近事业运势`
- `用梅花易数看明天出行，报数 3 和 7`
- `分别用当前时刻和午时各起一卦，对比一下`

AI 会自主选算法、调用引擎精确起课，再给出解卦。信息不足会先问你，也可以要求「换个时辰/参数」再占对比。

- **选算法**：输入框旁可指定 大六壬 / 小六壬 / 六爻 / 梅花（默认自动）。
- **简略 / 详细**：结果可看「简略」（课盘+结论）或「详细」（推导过程+逐步解读）。
- **分享 / 应验**：一键生成分享图；标记「应验/未应验」会累积你的准确率。

### ⚙️ 自定义你的 AI

右上角「⚙️ 自定义 AI API」可填 **Base URL / Model / API Key / Temperature**，使用任意 OpenAI 兼容服务（DeepSeek、通义、豆包、Kimi、智谱、Ollama 等）。留空则用服务端默认。

### 🔧 高级用法 · 手动精确起课

点「高级用法」可手动指定算法与参数（大六壬选日干/日支/时支/月将；小六壬填月/日/时；六爻摇卦；梅花报数），查看**天地盘 / 四课 / 三传**并回放推导，再用 AI 解读当前课盘。

### 📖 侧边栏

- **术语速查**：官鬼 / 天将 / 旬空 等术语即点即查（结果里也可悬停释义）。
- **历史回看**：此前的占卜保存在本浏览器，可回看 / 删除。
- **应验复盘**：按事类 / 算法看你的应验率与可靠性。

### 🌓 主题

右上角切换亮 / 暗主题。
